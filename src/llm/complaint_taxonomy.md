# 불만 유형 분류 체계 (v0.5)

Olist 리뷰(주로 1~3점)를 불만 유형별로 분류하기 위한 기준 문서.
LLM 분류 프롬프트와 사람 라벨링이 모두 이 문서를 기준으로 한다.

## 기본 원칙

1. **제목과 본문을 함께 본다.** 리뷰 제목(review_comment_title)이 있으면 본문(review_comment_message)과 함께 읽고 판단한다. 본문에 없는 불만이 제목에만 있어도 라벨을 부여한다.
2. **점수가 아닌 텍스트 기준으로 분류한다.** 1점이라도 텍스트에 불만이 없으면 NO_COMPLAINT, 3점이라도 불만이 있으면 해당 유형을 부여한다.

## 분류 방식

- **labels (다중 라벨)**: 리뷰에서 언급된 불만 유형을 모두 부여한다. `|`로 구분한다. (예: `NOT_RECEIVED|SERVICE`)
- **primary_label (주 원인 1개)**: labels 중 아래 **주 원인 우선순위**에 따라 1개를 고른다. 반드시 labels에 포함된 값이어야 한다.
- **NO_COMPLAINT, UNCLEAR**는 다른 유형과 함께 쓰지 않는다.
- **OTHER**는 다른 유형에 해당하지 않는 불만이 있을 때만 쓴다.

## 유형 정의

| 코드 | 이름 | 정의 |
|---|---|---|
| NOT_RECEIVED | 미수령 | 리뷰 작성 시점에 주문한 상품을 **전혀** 받지 못한 상태. 배송 완료로 표시됐지만 받지 못한 경우 포함. |
| WRONG_MISSING | 오배송·누락 | 고객이 **주문 시 고른 것**(상품·옵션·색상·수량)과 다른 것이 왔거나 일부가 빠진 경우. "일부만 받고 나머지 대기 중"인 분할 배송도 포함. |
| DAMAGED | 파손·불량 | 배송 중 파손, 작동 불능, 개체 결함, 사용 흔적(중고 의심) 등 받은 시점부터 사용할 수 없는 상태(규칙 J). 손상 없이 포장만 미흡한 경우는 제외. |
| NOT_AS_DESCRIBED | 설명 불일치 | 주문한 상품이 왔지만 **광고·사진에 표시된 내용**과 크기·소재·사양·구성이 다른 경우. 사진 속 구성품 누락, 상품 정보 부족·누락, 근거 있는 정품 아님·위조품 판단(규칙 F) 포함. |
| LOW_QUALITY | 품질 불만 | 상품의 정체는 기대와 같지만 품질·마감·내구성·성능이 기대에 못 미치는 경우. 취향 불만, 막연한 기대 미달("더 튼튼할 줄 알았다", "생각보다 작다"), 고객 스스로 확인을 잘못했을 수 있다고 인정한 불만 포함. 상품의 정체 자체가 다르면 NOT_AS_DESCRIBED(규칙 N). 이유 없는 불만족은 UNCLEAR. |
| SHIPPING_COST | 배송비·수령 불편 | 배송비가 비싸거나 중복 부과된 경우, 우체국 직접 수령 등 수령 방식이 불편한 경우, 반품 배송비 부담. |
| DELAY | 배송 지연 | 예정일을 넘겨 도착했거나, 기한 내라도 배송이 오래 걸렸다는 불만. 미수령 상태에서 예정일 경과·장기 대기를 언급하면 NOT_RECEIVED와 함께 부여. |
| SERVICE | 응대·환불 | 판매자·플랫폼의 구체적인 처리 문제(답변 없음, 연락 불가, 안내 부재, 결제 후 품절, 환불·교환·취소 지연·거부). 판매자가 지연 사유·배송 예정·문제 상황을 고객에게 알리지 않는 안내 부재도 포함한다. 세부 기준은 규칙 H. **부가 라벨 성격**으로, 다른 불만이 없을 때만 주 원인이 된다. 집계는 다중 라벨 기준으로 한다. |
| OTHER | 기타 | 위 유형에 해당하지 않는 구체적 불만(예: 상품 옵션 구색, 손상 없는 배송 포장 미흡, 송장 미발행·미동봉). |
| UNCLEAR | 판단 불가 | 의미 없는 텍스트(숫자, 상품명만 기재, "할 말 없음"), 이유 없는 불만족("마음에 안 듦", "반품 원함"만 있는 경우), 이유 없는 환불 요구(규칙 S). |
| NO_COMPLAINT | 불만 없음 | 텍스트에 불만이 드러나지 않음(칭찬, 중립). |

## 주 원인 우선순위

labels에 여러 유형이 있으면 아래 순서에서 가장 앞선 유형을 primary_label로 고른다.

```
NOT_RECEIVED > WRONG_MISSING > DAMAGED > NOT_AS_DESCRIBED > LOW_QUALITY > SHIPPING_COST > DELAY > SERVICE
```

- OTHER, UNCLEAR, NO_COMPLAINT는 위 8개 유형이 하나도 없을 때만 주 원인이 된다.
- SERVICE는 다른 불만이 없을 때만 주 원인이 된다.

## 판단 규칙

1. **NOT_RECEIVED vs DELAY**: "아직 못 받았다"가 명시되거나 문맥상 못 받은 것이 분명하면 NOT_RECEIVED. 이때 지연·경과 기간·기한 초과를 표현하면 DELAY를 함께 부여한다(규칙 K). 늦었다는 표현만 있고 현재 수령 여부를 알 수 없거나, 늦게라도 받았으면 DELAY만 부여한다(규칙 L).
2. **NOT_RECEIVED vs WRONG_MISSING**: 주문 전체를 못 받았으면 NOT_RECEIVED, 일부만 받았으면(분할 배송 포함) WRONG_MISSING.
3. **WRONG_MISSING vs NOT_AS_DESCRIBED**: 아래 경계 판정 규칙 A를 따른다.
4. **NOT_AS_DESCRIBED vs LOW_QUALITY**: 광고·사진·설명과의 차이를 언급하거나 상품의 정체 자체가 기대와 다르면(재질·종류 오인, 규격 불일치, 호환 불가) NOT_AS_DESCRIBED. 그런 언급 없이 품질이 나쁘거나 막연히 기대에 못 미친다고만 하면, 또는 고객 스스로 확인을 잘못했을 수 있다고 인정하면 LOW_QUALITY(규칙 N).
5. **DAMAGED vs LOW_QUALITY**: 아래 경계 판정 규칙 B를 따른다.
6. **SERVICE**: 환불·교환을 **요구**하는 것만으로는 부여하지 않는다. 응대·처리의 **실패**를 언급할 때 부여한다.
7. **SHIPPING_COST vs NOT_RECEIVED**: 우체국 등에서 직접 찾아왔다면 결국 받은 것이므로 NOT_RECEIVED가 아니라 SHIPPING_COST.

## 경계 판정 규칙

자주 헷갈리는 경계는 아래 규칙을 우선 적용한다.

| | 경계 | 판정 |
|---|---|---|
| A | WRONG_MISSING vs NOT_AS_DESCRIBED | 광고·사진·설명을 **명시적으로 언급**하면 NOT_AS_DESCRIBED, 언급 없이 다른 상품이 왔다고 하면 WRONG_MISSING |
| B | DAMAGED vs LOW_QUALITY | **받았을 때부터** 결함·작동 불가면 DAMAGED, **사용 후** 약해지거나 망가지면 LOW_QUALITY. 결함이 생긴 시점이 텍스트로 드러나지 않으면 DAMAGED |
| C | 일부 vs 전체 미수령 | 주문 상품 중 **일부만** 못 받았다고 하면 WRONG_MISSING, **전체**를 못 받았으면 NOT_RECEIVED |
| D | 낮은 점수 + 긍정 텍스트 | 불만 표현이 없으면 NO_COMPLAINT. 상품 설명과의 차이를 언급해도 최종적으로 만족·추천을 표현하면 NO_COMPLAINT |
| E | 포장 미흡(손상 없음) | OTHER |
| F | 위조품 의심 | "가짜다"처럼 단정하거나 전문가 판정 등 근거가 있으면 NOT_AS_DESCRIBED. "정품이길 바란다"처럼 걱정만 표현하면 체크하지 않음 |
| G | 포장 관련 | 제조사 상자·설명서·보증서 등 **상품 구성품** 누락은 WRONG_MISSING. **배송용 포장**이 허술하거나 상자가 열린 채 왔지만 손상이 없으면 OTHER. 단, 사진·광고·설명을 언급한 구성품 누락은 규칙 A를 우선해 NOT_AS_DESCRIBED |
| H | SERVICE 기준 | **부여**: 문의 무응답·무시, 연락 수단 없음, 문제 상황·지연 사유·배송 예정 안내 부재, 결제 후 품절·취소·환불·교환 처리 문제. **미부여**: 구체적 내용 없는 감정적·일반적 비판, 요청 후 아직 기한이 남았거나 기다리는 중이라 실패가 확인되지 않은 경우 |
| I | 송장 | 송장(nota fiscal) 미발행·미동봉은 OTHER |
| J | 수령 시점 사용 불가 | 받은 시점부터 사용할 수 없는 상태(더러움, 기기 인식 불가, 배터리 방전, 결함이 있는 채 도착 등)는 DAMAGED |
| K | 미수령 + 지연 | 미수령 리뷰에서 지연, 오래 걸림, 경과 기간, 기한 초과 중 하나라도 표현하면 NOT_RECEIVED와 DELAY를 함께 부여. 상품을 전혀 못 받은 리뷰에서 "오늘까지도(até hoje)", "현재까지(até o momento, até agora, até o presente momento)", "아직도 기다린다"처럼 계속 못 받고 있는 상태를 표현하면 DELAY를 함께 부여. "안 왔다"만 있으면 NOT_RECEIVED만 부여. 일부만 받은 경우(WRONG_MISSING)에는 이 규칙을 적용하지 않음 |
| L | 수령 여부 불명확한 지연 | "기한 내 도착하지 않았다", "기한이 지났다", "지연"처럼 늦었다는 표현만 있고 현재 수령 여부가 불명확하면 DELAY만 부여. NOT_RECEIVED는 "아직 못 받았다"가 명시되거나 문맥상 못 받은 것이 분명할 때만 부여 |
| M | 도착 시점 결함 표현 | "~한 상태로 왔다(veio com ~)"처럼 도착 시점의 결함·고장은 DAMAGED (규칙 J 보강) |
| N | 상품 오인·규격 불일치 | 상품의 정체 자체가 기대와 다른 경우(재질·종류를 오인하고 구매, 규격 불일치, 호환 불가)에만 NOT_AS_DESCRIBED. 막연한 기대 미달("더 튼튼할 줄 알았다", "생각보다 작다")은 LOW_QUALITY. 고객 스스로 확인을 잘못했을 수 있다고 인정하면 LOW_QUALITY. 주문한 것과 다른 상품이 배송된 경우는 규칙 N이 아니라 규칙 A(광고 언급 없으면 WRONG_MISSING)를 따른다. 규칙 N은 받은 상품이 주문한 그 상품이지만 고객이 정체를 잘못 알았던 경우에 적용한다 |
| O | 부품 없음 vs 방전·고장 | 원래 들어 있어야 할 부품(예: 시계 배터리)이 없으면 WRONG_MISSING, 들어 있지만 방전·고장이면 DAMAGED. 원래 포함되지 않는 부품(예: 별도 구매가 필요한 배터리)이 없다는 불만은 규칙 O에 해당하지 않는다 |
| P | 결제 후 품절 통보 | 결제 후 품절에서 통보까지 걸린 기간은 DELAY로 보지 않음. 늦은 통보는 SERVICE |
| Q | 포장 불량 + 실제 손상 | 포장 불량으로 상품이 실제 손상되면 DAMAGED만 부여. OTHER는 손상 없이 포장만 허술할 때 |
| R | 불명확한 배송 문제 | 배송 과정에 문제가 있었다고만 하고 수령·지연 여부가 불명확하면 OTHER |
| S | 이유 없는 환불 요구 | 이유 없이 환불(estorno)만 요구하면 UNCLEAR |

## 유형별 판단 예시 (파일럿에서 애매했던 사례)

### NOT_RECEIVED
- "배송을 너무 질질 끈다, 아직 못 받았다" (제목: 배송 지연) → `NOT_RECEIVED|DELAY`. 고객이 '지연'이라 표현해도 상태는 미수령.
- "배송 지연으로 평가할 수 없다" (제목: 상품이 오지 않음) → `NOT_RECEIVED|DELAY`. 제목으로 미수령 확인.
- "추적상 11일 배송 완료인데 받지 못했다" → `NOT_RECEIVED`.
- "상품을 받으려면 어떻게 해야 하나, 여전히 원한다" → `NOT_RECEIVED`. 직접 언급은 없지만 문맥상 미수령.

### WRONG_MISSING
- "TV 거치대 2개 주문, 1개만 옴, 두 번째 기다리는 중" → `WRONG_MISSING`. 분할 배송 포함.
- "두 상품 모두 9/5 도착 예정이었는데 하나만 옴" → `WRONG_MISSING|DELAY`, 주 원인 WRONG_MISSING.
- "오토바이용을 기다렸는데 자전거용이 옴" → `WRONG_MISSING`. 광고 언급 없음(규칙 A).
- 제목 "잘못된 상품" + 본문 "메일에 답이 없다" → `WRONG_MISSING|SERVICE`. 제목에서 오배송 확인.

### DAMAGED
- "이미 사용한 것 같다, 더럽고 긁혀 있다" → `DAMAGED`. 사용 흔적 포함.
- "핀으로 찌른 듯한 작은 구멍" → `DAMAGED`. 경미해도 받았을 때부터 있던 결함.
- "일부 브러시가 모가 휘거나 마른 채로 왔다" → `DAMAGED`. 수령 시점 결함(규칙 B).
- "시계 바늘이 부정확하고 조절 버튼이 빠졌다" → `DAMAGED`. 결함 시점이 불명이라 기본값 적용(규칙 B).
- "늦게 왔고 파손돼 있었다" → `DAMAGED|DELAY`, 주 원인 DAMAGED(우선순위).
- "새 상품이고 괜찮은데 상자가 밀봉되지 않았다" → DAMAGED 아님. `OTHER`(포장 미흡).

### NOT_AS_DESCRIBED
- "광고와 다르게 왔다" → `NOT_AS_DESCRIBED`. 광고를 기준으로 언급.
- "사진엔 보온병 커버가 있었는데 동봉되지 않았다" → `NOT_AS_DESCRIBED`. 사진 속 구성품 누락.
- "올블랙 시계를 샀는데 은색 버클로 옴, 사진엔 검은 버클과 각인이 있었다" → `NOT_AS_DESCRIBED`. 사진을 명시적으로 언급(규칙 A).
- "정품 인형인 줄 알았는데 중국산, 설명에 제조지가 없다" → `NOT_AS_DESCRIBED`. 정보 부족·정품 여부.
- "엡손 정품이라 했는데 위조품" → `NOT_AS_DESCRIBED`.
- "배터리 미포함, 영어 매뉴얼, 어떤 배터리를 써야 할지 모름" → `NOT_AS_DESCRIBED`. 상품 정보 부족.
- "면인 줄 알고 샀는데 합성 소재였다", "내 기기와 호환되지 않는다" → `NOT_AS_DESCRIBED`. 상품의 정체 자체가 기대와 다름(규칙 N).

### LOW_QUALITY
- "상품은 맞게 왔는데 너무 작아서 싫다" (설명 언급 없음) → `LOW_QUALITY`. 막연한 기대 미달(규칙 N).
- "나무가 더 두꺼울 줄 알았는데 너무 얇다" → `LOW_QUALITY`. 막연한 기대 미달(규칙 N).
- "향이 너무 달다" → `LOW_QUALITY`. 취향 불만.
- "자석이 약해 일주일 만에 안 닫힘, 실이 풀림" → `LOW_QUALITY`. 사용 후 약해짐(규칙 B).
- "광고를 잘 안 봤는데 소재가 마음에 안 든다" → `LOW_QUALITY`. 고객이 확인을 잘못했다고 인정(규칙 N).

### SHIPPING_COST
- "배송비를 냈는데 우체국에 직접 찾으러 가야 했다" → `SHIPPING_COST`.
- "같은 판매처 2개 상품에 배송비를 두 번 받았다" → `SHIPPING_COST`.
- "배송비가 너무 비싸다, 무료배송 해달라" → `SHIPPING_COST`.

### DELAY
- "기한 내에 왔지만 너무 오래 걸렸다" → `DELAY`.
- "조금 늦었지만 괜찮았다" → `DELAY`.

### SERVICE
- "환불을 원한다"만 있는 경우 → SERVICE 아님.
- "영수증을 버려서 교환을 못 했다" → SERVICE 아님(고객 사정).

### OTHER
- "원하던 향 옵션이 없었다" → `OTHER`(상품 구색).

### UNCLEAR
- "3", "아무 말도 하고 싶지 않다", 상품명만 기재 → `UNCLEAR`.
- "마음에 안 들어요, 반품하고 싶어요" → `UNCLEAR`. 이유 없는 불만족.
- 이유 없이 "환불(estorno)해 주세요"만 있는 경우 → `UNCLEAR`(규칙 S).

### NO_COMPLAINT
- 2점인데 "아주 좋아요" → `NO_COMPLAINT`. 텍스트 기준.
- 2점, "사이트에서는 달라 보여 더 클 줄 알았지만 만족, 강력 추천" → `NO_COMPLAINT`. 설명 차이를 언급했지만 최종적으로 만족·추천(규칙 D).
